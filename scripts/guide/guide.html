UkratkoŠto je Fleet

Jedna flota, pet sučelja

Fleet nađe svaku živu sesiju coding agenta na svakoj mašini (tmux pane ili iTerm tab), pokaže što radi i pusti te da joj pišeš, odgovaraš, preimenuješ je, otvoriš novu ili posao prebaciš drugdje. Svaka mašina vrti isti mali web server, koji spaja sesije svojih peerova, pa bilo koji URL pokazuje cijelu flotu.

web UI · desktop

Keyboard-first master–detail od 1024 px naviše: sidebar, chat, details panel, board.

PWA · mobitel

Add to Home Screen preko Tailscalea. Swipe geste, quick replyji, mic za operatora.

Fleet.app

Tauri ljuska oko istog UI-ja: Dock, ⌘-Tab, pravi meniji, ⌘N, Attach u iTerm.

fleet · CLI

list, peek, send, spawn, handoff… s -H <host> na bilo kojoj mašini.

fleet watch · TUI

Živi dashboard u terminalu; javi kad sesija završi ili zapne.

fleet mcp · skill

Cijeli CLI kao MCP alati, pa agenti sami upravljaju flotom.

Tri harnessa: Claude Code, Codex i pi. Svi se nađu, prikazuju i voze isto; harness i model biraš kod spawna. Svi screenshotovi u ovom vodiču su s izmišljenim demo podacima (firma „Acme”, hostovi laptop, workstation, devbox).

01 · SesijeLista, filteri, status#/

Sve sesije sa svih mašina na jednoj listi

Svaki red: status, naslov, host, cwd, backend (tmux/iTerm), harness chip (Codex, pi), context meter u postotku i koliko je prošlo od zadnje aktivnosti. Sesije koje čekaju tebe imaju narančasti okvir i razlog: permission: Bash(…), question: ….

  • Needs you, Busy, Idle i Scheduled (samo sesije koje je pokrenuo job) kao filteri, plus filter po hostu. Brojači u headeru broje sve.
  • Pretraga ⌘F po imenu, naslovu i cwd-u; filtrira i Dormant i Recently closed.
  • Naslov se uređuje na licu mjesta (klik, ⌘E, F2, long press na mobitelu). Claudeov /rename je izvor istine, tmux ime ga prati. Bez imena, haiku sam smisli kratki naslov nakon prvog odgovora.
  • Sesija u stacku nosi chip sa slojevima; sesija koju je pokrenuo job nosi chip sa satom.
  • Banner kad je neki host nedostupan. Tab title je (3) Invoice rounding fix · Fleet.
02 · ChatČitanje i pisanje#/s/<host>/<id>

Chat čita transcript, composer tipka u tmux

Chat se čita ravno iz Claudeovog transcripta i osvježava svake 3 s. Odgovori su renderirani markdown (tablice, liste, kod), skillovi i slash komande su chip na vrhu poruke, shell komande (!) su mono blok, a zalijepljeni tekst je zaseban blok. Narracija između tool callova su tihe „progress notes” koje se mogu sakriti. Svaka poruka agenta ima gumb za čitanje naglas.

draftovi

Neposlani tekst se čuva po sesiji, kroz prebacivanje i restart.

quick replyji i tipke

Continue, Yes, „Run the tests”, „Commit & push” (iz configa) plus Esc, Enter, ↑, ↓.

prilozi

Drag, paste ili spajalica: file se uploada na host sesije, a u poruku ide njegova apsolutna putanja.

glasovni unos

Mic snimi, transkribira i doda tekst; nikad ne šalje sam. Treba HTTPS origin (npr. tailscale serve).

linkovi na fileove

Putanje koje agent spomene postaju linkovi s previewom (vidi dolje).

greške

Neposlana poruka ostaje kao „Not sent: …” s Retry i Edit.

03 · PitanjaAskUserQuestion

Odgovori na Claudeovo pitanje jednim klikom

Kad Claude postavi pitanje s opcijama (AskUserQuestion), chat ga prikaže kao karticu: opcije, preporučena označena, polje „Something else…” za slobodan odgovor, Dismiss i Answer. Odgovor ide direktno u sesiju.

04 · BriefDetails panel, file preview⌘I

Handover bilješka koja se piše sama

Svaka sesija ima brief: sažetak u 1–2 rečenice, todoe s checkboxovima i napretkom (3/5) i resurse izvučene iz transcripta (git branch i worktree, PR-ovi, issueji, specovi, fileovi, linkovi). Generira ga haiku tek nakon 60 s mirovanja; ručne izmjene uvijek pobjeđuju. New session from here… otvori formu s briefom kao prvim promptom i izborom Hand off (zasebna sesija; CLI: fleet spawn --from) ili Sibling (ista sesija u stacku, stvori ga ako ga nema).

  • Open in VS Code / Cursor za cwd i svaki worktree; za drugi host otvara Remote SSH.
  • Attach command (fleet -H workstation enter …) za copy; u Fleet.app gumb Attach otvara iTerm tab.
  • Auto-name → Run now i zadnji run naminga.

File preview

Putanja koju agent spomene (docs/billing/rounding.md, src/x.ts:42) postaje link. Klik otvori preview: markdown renderiran, kod s brojevima linija i istaknutom linijom, slike, PDF. Download, Open on <host> (otvori na toj mašini) i Copy path. Servira samo fileove unutar $HOME ili cwd-a, nikad ~/.ssh ni .env.

05 · Diff reviewFiles changed, uživo#/review

PR review sa sesijom, dok još kodira

GitHubov „Files changed”, ali nad radnim stablom sesije, ne nad PR-om. Diff gleda sve checkoute u kojima sesija radi: njen cwd i svaki worktree u kojem editira datoteke. Sesija iz meta repoa koja vodi tri PR-a kroz tri worktreeja vidi sva tri, svaki prema svom default branchu, s necommitanim i novim datotekama. Otvara se diff gumbom u headeru sesije ili s ⌘K → Review changes; Esc vraća u sesiju.

  • Uživo: diff se osvježava svake 2 s dok agent radi; datoteka koju je upravo promijenio dobije obrub i istakne se u stablu.
  • Viewed po datoteci, kao na GitHubu, i sam se odznači kad se datoteka ponovno promijeni. Unified ili split, collapse all.
  • Diff ne dira repo: radno stablo snimi kroz privremenu kopiju indexa, bez refova i bez stashanja.

Komentar ide u sesiju, odgovor u thread

Označi kod mišem i klikni Comment on lines, ili klikni broj linije (+ na hover, shift-klik za raspon). Komentar ide u sesiju kao prompt s datotekom, rasponom linija i označenim kodom, pa agent točno zna o čemu pričaš. Odgovor se čita iz transcripta i pojavi se u threadu ispod linija, a ostaje i normalan dio razgovora sesije.

  • Single comment odmah ide u sesiju. Start a review sprema komentare kao pending, a Submit review (n) ih šalje sve u jednom promptu, uz opći komentar. Svaki thread dobije odgovor na review.
  • Thread pokazuje stanje: Sent → Queued (sesija je zauzeta) → Claude is working… → odgovor. Reply nastavlja razgovor u istom threadu; Resolve ga zatvara.
  • Kad agent promijeni linije ispod komentara, thread postaje Outdated; ako linije nestanu iz diffa, thread ide na vrh datoteke.
06 · BoardSmart grouping⌘B

Sesije složene po poslu, ne po mašini

Board je Kanban u kojem je svaka kolona jedan work stream. Grupe slaže haiku pass svakih 10 minuta (jedan host za cijelu flotu, model call samo za nove sesije). Bez modela grupira po repou. Kartica pokazuje status, host, razlog čekanja, context i starost; sesije koje čekaju idu na vrh kolone.

  • Klik na ime kolone = preimenuj. Drag kartice u drugu kolonu = premjesti. „Drop here for a new group” i „+ New group” = nova grupa. Drag headera = novi redoslijed.
  • Ručne izmjene su zaključane: grouping pass ih nikad ne poništi.
  • Regroup pokrene pass odmah; header kaže „grouped 3m ago · 1 model call”.
07 · StackoviViše sesija, jedan kontekst

Stack: N sesija dijeli jedan StackBrief

Kad je posao prevelik za jednu sesiju, napraviš stack: sesije na jednom ili više hostova dijele jedan markdown s kontekstom (sažetak, resursi, bilješke). Spawn sibling pokrene novu sesiju u stacku, i na drugoj mašini; njen prvi prompt počne linijom koja joj kaže gdje je zajednički kontekst. Stack ima svoju kolonu na boardu i traku na vrhu sesije.

StackBrief se uređuje cijeli (s konfliktom ako ga je netko drugi promijenio u međuvremenu), stack se preimenuje klikom na labelu, a Delete stack ostavlja sesije da rade. CLI: fleet stack spawn --on devbox.

08 · Nova sesijaSpawn s bilo kojeg uređaja⌘⇧O · ⌘N

Nova sesija na bilo kojem hostu

Biraš host, direktorij (Start directories iz postavki), agenta (Claude Code, Codex, pi), model i opcionalni prvi prompt, s prilozima i glasovnim unosom. ⌘Enter pokreće. Ime ne upisuješ: sesija dobije naslov nakon prvog odgovora. Neposlani prompt ostaje kao draft tjedan dana. Kad sesija krene, Fleet je sam otvori.

Fleet.app

Isti UI kao macOS app (Tauri 2, system WebKit, ~10 MB). Pravi meniji, ⌘N kao File → New Session, nativni title bar, Attach otvara iTerm tab s fleet -H <host> enter. Otvara lokalni server ili desktop.url (npr. onaj na workstationu); svaki server pokazuje cijelu flotu.

10 · OperatorRazgovaraj s flotom#/operator

Glasovni operator

Operator je Claude sesija koju server pokrene na zahtjev, s briefom dispečera: odgovara kratko i glasom, uvijek prvo pogleda stanje, djeluje samo na nedvosmislen cilj, a zatvaranje ili prekid traži izričito „da”. Tapneš mic, kažeš što trebaš, odgovor se pročita naglas (OpenAI glas ili glas uređaja, brzina 1×–2×). Dok je ekran otvoren, najavi sesije koje te počnu trebati. Jedan operator za sve uređaje; nakon sat vremena mirovanja dobije /clear i kreće ispočetka.

11 · MemosSnimi razgovor#/memos

Voice memos: sastanak postaje transcript

Jedan gumb snima razgovor bez limita trajanja. Audio se reže u segmente od 5 minuta koji se transkribiraju dok snimanje traje, a na kraju memo dobije naslov i sprema se kao markdown. Ništa se ne gubi: chunkovi idu u IndexedDB dok ih server ne potvrdi, prekinuto snimanje se spasi kod sljedećeg otvaranja. Iz memoa jednim klikom Start session; vokabular (imena ljudi, domenski pojmovi) poboljšava transkripciju.

12 · Pull requestsŠto čeka tebe#/prs · fleet prs

PR-ovi koji te trebaju, po kolonama

Preko gh na odabranom hostu: Unseen mentions, Waiting on me, moji u reviewu, spremni za merge, moji draftovi i Waiting on author. Rub kartice ide od zelenog do crvenog kako PR stari („rotting”). Checks, review status, veličina, komentari. PR jednim klikom ide u worktree i dobije sesiju s promptom koji kaže o čemu je PR; sesije i PR-ovi su povezani u oba smjera.

CLI: fleet prs, fleet pr checkout, fleet pr spawn, fleet pr seen, fleet pr cleanup-worktrees (makne worktreeje gotovih PR-ova).

13 · BotsAgenti iz recepta#/bots · fleet bots

Bots: routines na tvojim mašinama

Cron raspored u configu hosta, prompt inline ili iz filea, harness i model po botu. Raspored je napisan ljudski („Weekdays at 07:00”). Svaki run se pamti s outcomeom (spawned, skipped, missed, failed), a sve sesije koje bot sesija pokrene pripadaju istom runu, prikazane kao stablo. Prekidač za pauzu, Run now (s „Run anyway” ako prethodni još radi), prompt file otvoriš u editoru.

14 · NotesMarkdown explorer#/notes · ⌘⇧E

Bilješke bilo kojeg hosta

Ako host ima web.notes.root, Fleet pokazuje stablo foldera, nedavno mijenjane bilješke i pretragu (riječi, "fraze", #tag) s istaknutim pogocima. Bilješka se prikazuje renderirana s frontmatterom kao tablicom i [[wiki]] linkovima. Send to session stavi putanju bilješke u composer odabrane sesije. Paleta ⌘K pretražuje i bilješke.

15 · UsageLimiti pretplate#/usage · fleet usage

Koliko je još ostalo do limita

Isti brojevi kao Claude Codeov /usage, za svaki account logiran na nekoj mašini (hostovi na istom accountu dijele karticu): trenutna sesija, tjedni limit za sve modele, tjedni po modelu, extra usage. Limit koji trenutno veže je označen kao binding, a reset piše kad.

16 · OporavakNakon rebootafleet restore

Dormant i Recently closed

Fleet stalno sprema snapshot tmux layouta. Nakon reboota sesije postanu dormant: vide se ispod liste i na boardu, s tmux imenom, Claude naslovima, brojem windowa i paneova. Resume vrati isti layout i svaki Claude pane s --resume, pa grupe, stackovi i briefovi ostaju. Recently closed čuva zatvorene sesije 7 dana, za slučaj da si zatvorio krivu.

fleet restore              # lista dormant sesija
fleet restore legacy-import
fleet restore --all
fleet restore --closed     # nedavno zatvorene
17 · PostavkeIzgled, repoi, direktoriji#/settings · ⌘,

Teme, veličina teksta i postavke flote

Po pregledniku: veličina teksta za cijeli UI, tema (Default, Earth, Dusk), light/dark/system, font terminala, progress notes i send delay (Off, 3 s, 5 s). Za cijelu flotu, spremljeno u config svakog hosta:

  • Start directories: jedna lista labela s putanjom po hostu; svaka ćelija pokaže postoji li direktorij na tom hostu, Save piše na sve hostove.
  • Git repos: auto-sync (launchd timer), interval, skenirani direktoriji i svaki repo s branchom, ↓↑, zadnjim syncom i ishodom (updated, ahead, blocked zbog uncommitted promjena). Sync now po repou ili Sync all.
18 · TerminalCLI i TUIfleet

Isto, iz terminala

Goli fleet je živi dashboard: sesije sortirane da one koje te trebaju budu gore, prompt i repo ispod naslova, događaji (pojavila se, završila, zapela dulje od 300 s) u donjem panelu. Brojevi 1–0 skaču na sesiju.

fleet list -a                          # sve sesije, svi hostovi (--json: jedan array)
fleet peek invoice                     # što sesija trenutno pokazuje
fleet send invoice "run the tests"     # utipkaj i stisni Enter
fleet -H workstation spawn "migrate the index" --dir ~/Code/acme-api --harness codex
fleet spawn --from invoice             # nova sesija iz briefa
fleet handoff --dir ~/Code/acme-api     # prebaci ovaj posao u novu sesiju, s briefom
fleet pr spawn acme-web#1310           # PR u worktree + sesija na njemu
fleet name --apply                     # daj svim sesijama prava imena
fleet enter invoice · fleet last       # uđi u tmux sesiju bilo gdje · natrag na prethodnu
fleet tmux stale                       # idle shellovi koje nitko ne koristi
fleet brief invoice · fleet stack …    # briefovi i stackovi
fleet repos sync · fleet jobs run dependency-audit
fleet doctor                           # dostupnost hostova, verzije, config

Target se resolva po naslovu, imenu, prefiksu session id-ja ili pidu. Komande koje tipkaju u živog agenta nikad ne pogađaju: ako dvije sesije jednako odgovaraju, dobiješ grešku s kandidatima.
