UkratkoŠto je Fleet

Jedna flota, pet sučelja

Fleet nađe svaku živu sesiju coding agenta na svakoj mašini (tmux pane ili iTerm tab), pokaže što radi i pusti te da joj pišeš, odgovaraš, preimenuješ je, otvoriš novu ili posao prebaciš drugdje. Svaka mašina vrti isti mali web server, koji spaja sesije svojih peerova, pa bilo koji URL pokazuje cijelu flotu. Oko sesija su moduli za ostatak dana: Inbox, Productive taskovi, PR-ovi, Slack linkovi, botovi, memos i notes.

web UI · desktop

Keyboard-first od 1024 px naviše: gornja traka s modulima, lista, chat, details panel, board.

PWA · mobitel

Add to Home Screen preko Tailscalea. Swipe geste, quick replyji, mic za operatora.

Fleet.app

Tauri ljuska oko istog UI-ja: Dock, ⌘-Tab, pravi meniji, ⌘N, Attach u iTerm. Ista ljuska pakira Brain.app i Fin.app.

fleet · CLI

list, peek, send, spawn, handoff… s -H <host> na bilo kojoj mašini.

fleet watch · TUI

Živi dashboard u terminalu; javi kad sesija završi ili zapne.

fleet mcp · skill

Cijeli CLI kao MCP alati, pa agenti sami upravljaju flotom.

Tri harnessa: Claude Code, Codex i pi. Svi se nađu, prikazuju i voze isto; harness i model biraš kod spawna. Svi screenshotovi u ovom vodiču su s izmišljenim demo podacima (firma „Acme”, hostovi laptop, workstation, devbox).

01 · SesijeLista, filteri, hostovi#/

Sve sesije sa svih mašina na jednoj listi

Svaki red: točka statusa (tooltip kaže zašto čeka), naslov, host, cwd, backend (tmux/iTerm), harness chip (Codex, pi), context meter i vrijeme. Sesije koje čekaju tebe imaju narančasti okvir. Lista je složena po zadnjem promptu, ne skače dok je mišem držiš, a kad se presloži, redovi klize na novo mjesto.

  • Gornja traka (desktop): Sessions | Bots | Slack, status (Needs you, Busy, Idle) i host u popupima, pretraga ⌘F, List | Board, moduli (Inbox, operator, PR-ovi, Tasks, memos, notes, bots), gumbi hostova, pa Focus, Usage i Settings.
  • Bots, Slack i Apps (embed) sesije su sklonjene u svoj filter; u glavnoj listi se pojave samo kad te trebaju.
  • Članovi stacka su jedna grupa pod labelom stacka: vidi se zadnji, ostali iza „N more”. Sesija koja je javila da je gotova ima Done chip i svoju bilješku umjesto prvog prompta.
  • Chip 🤖 1 >_ 1 na redu: sesija vrti subagente ili shellove u pozadini.
  • Naslov se uređuje na licu mjesta (klik, ⌘E, F2, long press na mobitelu); gumb pored naslova ga regenerira. Bez imena, haiku smisli naslov po konvenciji <područje>-<što> iz briefa i prvih promptova.
02 · ChatČitanje i pisanje#/s/<host>/<id>

Chat čita transcript, composer tipka u tmux

Chat se čita ravno iz transcripta i osvježava svake 3 s. Odgovori su renderirani markdown, skillovi i slash komande su chip na vrhu poruke, shell komande (!) su mono blok, zalijepljeni tekst zaseban blok. Narracija između tool callova su tihe „progress notes”. Završni odgovori imaju gumb za čitanje naglas. Terminal view više ne postoji: sve što treba je u chatu.

Queue i pozadinski rad

Dok agent radi, Enter stavlja poruku u queue: ulazi jedna po runu, tek kad je sesija slobodna, nikad dok čeka tebe. Svaku možeš urediti, poslati odmah ili maknuti; Pause zadrži queue za ovaj run, a ⌘Enter u praznom composeru šalje prvu odmah. Iznad composera je panel s onim što radi u pozadini (subagenti s modelom i zadnjim toolom, background shellovi), kao Claude Codeov agent panel. Sesija kojoj je glavni turn gotov a subagenti još rade je idle: prima nove poruke. Kad context prijeđe 30 %, pojavi se Compact pill koji pošalje /compact.

draftovi

Neposlani tekst se čuva po sesiji, kroz prebacivanje i restart.

quick replyji i tipke

Continue, Yes, „Run the tests”, „Commit & push” (iz configa) plus Esc, Enter, ↑, ↓.

prilozi

Drag, paste ili spajalica: file se uploada na host sesije, a u poruku ide njegova apsolutna putanja.

glasovni unos

Mic snimi, transkribira i doda tekst; nikad ne šalje sam. Snimka koja se ne transkribira ne propada: ostaje za Retry.

linkovi na fileove

Putanje u odgovorima, promptovima i todoima postaju linkovi s previewom.

greške

Neposlana poruka ostaje kao „Not sent: …” s Retry i Edit.

03 · PitanjaAskUserQuestion

Odgovori na agentovo pitanje jednim klikom

Kad agent postavi pitanje s opcijama (AskUserQuestion), chat ga prikaže kao karticu: opcije, preporučena označena, polje „Something else…” za slobodan odgovor, Dismiss i Answer. Odgovor ide direktno u sesiju. Pitanje koje se vidi samo na ekranu terminala (a ne u transcriptu) Fleet pročita s panea i prikaže isto.

04 · BriefDetails panel, file preview

Handover bilješka koja se piše sama

Details panel je uvijek pored chata. Na vrhu su akcije: Review (diff), New (nova sesija odavde: Hand off preda posao s briefom, Sibling pokrene sesiju u istom stacku), Link (Slack) i Attach (iTerm tab u Fleet.appu), a gore desno ⏻ za Close ili Deactivate.

Ispod je brief: sažetak (zašto i što je sljedeće), Origin (task, Slack thread ili issue odakle je posao došao), Pull requests, todoi s napretkom (3/5) i ostali resursi iz transcripta (worktreeji, issueji, specovi, fileovi, linkovi). Generira ga haiku tek nakon 60 s mirovanja; ručne izmjene uvijek pobjeđuju. Hand off predaje origin, PR-ove i worktree, a zadatak ide ispod crte (CLI: fleet spawn --from).

File preview

Putanja koju agent spomene (docs/billing/rounding.md, src/x.ts:42) postaje link. Klik otvori preview: markdown renderiran, kod s brojevima linija i istaknutom linijom, slike, PDF. Download, Open on <host> i Copy path. Servira samo fileove unutar $HOME ili cwd-a, nikad ~/.ssh ni .env.

05 · GotovoAsk donefleet done

Sesija sama javi da je gotova

Kad agent završi i ništa ne čeka tebe, pokrene fleet done --note "…" i napiše kratku završnu poruku. Ništa se ne zatvara: sesija dobije Done chip, bilješka zamijeni prvi prompt u listi i na boardu, a na kraju razgovora je Done kartica s Close. Pročitaš i zatvoriš, ili napišeš novu poruku pa posao ide dalje. Uputu dobiju svi botovi i sve što oni pokrenu; isto pravilo može stajati u korisničkom CLAUDE.md.

06 · Diff reviewFiles changed, uživo#/review

PR review sa sesijom, dok još kodira

GitHubov „Files changed”, ali nad radnim stablom sesije, ne nad PR-om. Diff gleda sve checkoute u kojima sesija radi: njen cwd i svaki worktree u kojem editira datoteke. Sesija iz meta repoa koja vodi tri PR-a kroz tri worktreeja vidi sva tri, svaki prema svom default branchu, s necommitanim i novim datotekama. Otvara se diff gumbom u headeru sesije ili s ⌘K → Review changes; Esc vraća u sesiju.

  • Uživo: diff se osvježava svake 2 s dok agent radi; datoteka koju je upravo promijenio dobije obrub i istakne se u stablu.
  • Viewed po datoteci, kao na GitHubu, i sam se odznači kad se datoteka ponovno promijeni. Unified ili split, collapse all.
  • Diff ne dira repo: radno stablo snimi kroz privremenu kopiju indexa, bez refova i bez stashanja.

Komentar ide u sesiju, odgovor u thread

Označi kod mišem i klikni Comment on lines, ili klikni broj linije (+ na hover, shift-klik za raspon). Komentar ide u sesiju kao prompt s datotekom, rasponom linija i označenim kodom, pa agent točno zna o čemu pričaš. Odgovor se čita iz transcripta i pojavi se u threadu ispod linija, a ostaje i normalan dio razgovora sesije.

  • Single comment odmah ide u sesiju. Start a review sprema komentare kao pending, a Submit review (n) ih šalje sve u jednom promptu, uz opći komentar. Svaki thread dobije odgovor na review.
  • Thread pokazuje stanje: Sent → Queued (sesija je zauzeta) → Claude is working… → odgovor. Reply nastavlja razgovor u istom threadu; Resolve ga zatvara.
  • Kad agent promijeni linije ispod komentara, thread postaje Outdated; ako linije nestanu iz diffa, thread ide na vrh datoteke.
07 · BoardSmart grouping⌘B

Sesije složene po poslu, ne po mašini

Board je Kanban u kojem je svaka kolona jedan work stream. Grupe slaže haiku pass svakih 10 minuta (jedan host za cijelu flotu, model call samo za nove sesije). Bez modela grupira po repou. Kartica pokazuje status, host, razlog čekanja, context i starost; sesije koje čekaju idu na vrh kolone.

  • Klik na ime kolone = preimenuj. Drag kartice u drugu kolonu = premjesti. „Drop here for a new group” i „+ New group” = nova grupa. Drag headera = novi redoslijed.
  • Ručne izmjene su zaključane: grouping pass ih nikad ne poništi.
  • Regroup pokrene pass odmah; header kaže „grouped 3m ago · 1 model call”.
08 · StackoviViše sesija, jedan kontekst

Stack: N sesija dijeli jedan StackBrief

Kad je posao prevelik za jednu sesiju, napraviš stack: sesije na jednom ili više hostova dijele jedan markdown s kontekstom (sažetak, resursi, bilješke). Spawn sibling pokrene novu sesiju u stacku, i na drugoj mašini; njen prvi prompt počne linijom koja joj kaže gdje je zajednički kontekst. Stack ima svoju kolonu na boardu i traku na vrhu sesije.

StackBrief se uređuje cijeli (s konfliktom ako ga je netko drugi promijenio u međuvremenu), stack se preimenuje klikom na labelu, a Delete stack ostavlja sesije da rade. CLI: fleet stack spawn --on devbox.

09 · Nova sesijaSad ili kasnije⌘⇧O · ⌘N

Nova sesija na bilo kojem hostu

Sve su chipovi: host, direktorij (Start directories iz postavki), agent (Claude Code, Codex, pi), model. Default model i effort po harnessu dolaze iz Settings → Models (Default · Opus 5.5 · high). Opcionalno Slack: link na thread ili @osoba, pa sesija od starta razgovara tamo. Prvi prompt je zadnji, s prilozima i glasom; ⌘Enter pokreće. Ime ne upisuješ, a sesija se otvori čim krene. Codexov trust prompt Fleet odgovori sam.

Kasnije: scheduled sessions

When → Later zakaže sesiju za određeno vrijeme po satu tog hosta (Schedule on laptop). Isto iz CLI-ja: fleet schedule add "…" --at "tomorrow 07:30", ili vezano uz task: sesija krene na dan kad task počinje i prati datum ako se pomakne (vidi Tasks). Zakazane sesije stoje na vrhu ekrana Bots, s Cancel.

10 · InboxSve što čeka tebe#/inbox · ⌘⇧I

Jedan to-do za cijeli dan, koji se sam održava

Inbox skuplja sve što čeka tebe: review requestove, mentione i tvoje PR-ove (GitHub), taskove koji kasne ili su u tijeku (Productive), sesije koje čekaju, te poruke iz Slacka i Gmaila (scan kroz claude.ai konektore, samo čitanje, u radno vrijeme). Svaka stavka vodi na stvar koja čeka i sama nestane kad je izvor riješi, ili odmah na Done. Na vrhu je brief od nekoliko rečenica s linkovima, a stavke su u tri skupine: Quick wins, Waiting on you i tvoj posao.

Inbox vrti jedan host (najbolje onaj koji je stalno upaljen), ostali ga proxyjaju. Raspored scana (svakih N minuta, radni sati, dani) je u Settings → Inbox; Scan now ga pokrene odmah. Operator zna za inbox: pročita brief, označi stavke gotovima, pokrene scan.

11 · TasksProductive#/tasks · fleet tasks · ⌘⇧Y

Tvoji taskovi, i sesija na njima

Otvoreni Productive taskovi dodijeljeni tebi, u tri kolone: Due soon (rok za 3 dana ili kasni), In progress i To do. Filter po naslovu, broju, statusu ili tagu, po projektu, i „Idle” za one bez nedavne aktivnosti. Klik na task: status se mijenja na licu mjesta, a sesija se pokreće s promptom koji kaže o kojem je tasku riječ (link na task ide u prvi prompt, pa je sesija vezana uz njega).

U dijalogu taska sesiju pokreneš Now ili On start date: zakaže se za dan početka taska u odabrano vrijeme, prati datum ako se pomakne i preskoči se ako je task u međuvremenu zatvoren.

fleet tasks                            # kolone, kao na ekranu
fleet task status 2041 "in review"     # pomakni task
fleet task spawn 2041 "add the JPY case" -C ~/Code/acme-api
fleet task schedule 2090 --time 08:00  # sesija na dan početka
12 · Pull requestsŠto čeka tebe#/prs · fleet prs · ⌘⇧P

PR-ovi koji te trebaju, po kolonama

Preko gh na hostu koji servira UI, u panelu pored liste sesija: Unseen mentions, Waiting on me, moji u reviewu, spremni za merge, moji draftovi i Waiting on author. Rub kartice ide od zelenog do crvenog kako PR stari („rotting”). Checks, review status, veličina, komentari. PR jednim klikom ide u worktree i dobije sesiju s promptom koji kaže o čemu je PR; sesije i PR-ovi su povezani u oba smjera, na bilo kojem hostu.

CLI: fleet prs, fleet pr checkout, fleet pr spawn, fleet pr seen, fleet pr cleanup-worktrees (makne worktreeje gotovih PR-ova).

13 · SlackSesija u threadufleet slack link

Sesija koja neko vrijeme razgovara u Slacku

Sesiju povežeš s jednim Slack threadom, kanalom ili DM-om s osobom (@ime), na određeno vrijeme (30 min do tjedan dana, ili bez kraja) i s uputom što smije. Ono što ljudi tamo napišu ulazi u sesiju kad je slobodna, s imenom autora, a ona odgovara s fleet slack reply. Po defaultu se budi samo kad je netko spomene, piše joj u DM ili u threadu u kojem je već pisala (a tada sama procijeni je li poruka za nju); proactive mod vidi sve i javi se kad treba.

što Fleet jamči

Samo taj razgovor, samo do isteka, samo povezana sesija smije odgovoriti; tokeni su samo na hostu koji vrti bridge.

kako se poveže

Details → Link to Slack, New session → Slack, ili sesija sama kad je zamoliš („linkaj se na ovaj thread”). Istekli link se vraća s Link again.

gdje se vidi

Slack sesije imaju svoj filter (Sessions | Bots | Slack) i ne miješaju se s ostalima.

CLI

fleet slack link <url | @osoba> --for 2h --task "…", fleet slack, fleet slack unlink.

14 · BotsAgenti iz recepta#/bots · fleet bots · ⌘⇧L

Bots: routines na tvojim mašinama

Bivši „scheduled jobs”. Cron raspored u configu hosta, prompt inline ili iz filea, harness, model i opcionalno GitHub identitet (bot sesija tada na GitHubu radi kao GitHub App, ne kao ti). Raspored je napisan ljudski („Weekdays at 07:00”). Svaki run se pamti s ishodom (spawned, skipped, missed, failed), a sve sesije koje bot sesija pokrene pripadaju istom runu, prikazane kao stablo. Prekidač za pauzu, Run now, a fleet bots run <bot> --prompt "…" daje botu drugi zadatak uz njegov recept. Gotove bot sesije se zatvore same nakon 72 h (keep), osim ako čekaju tebe.

Fleet.app i ostali appovi

Isti UI kao macOS app (Tauri 2, system WebKit, ~10 MB). Pravi meniji, ⌘N kao File → New Session, nativni title bar, Attach otvara iTerm tab s fleet -H <host> enter, a gumb hosta otvara tmux na njemu. Ista ljuska kroz profile pakira i druge web appove (Brain.app, Fin.app). Ti appovi preko embed viewa (#/embed) uokvire sesije jednog direktorija kao svoj chat panel; takve sesije idu u filter Apps.

Focus u gornjoj traci pokreće focus na odabranom hostu: Do Not Disturb i gašenje appova koji ometaju.

16 · OperatorRazgovaraj s flotom#/operator

Glasovni operator

Operator je Claude sesija koju server pokrene na zahtjev, s briefom dispečera: odgovara kratko i glasom, uvijek prvo pogleda stanje, djeluje samo na nedvosmislen cilj, a zatvaranje ili prekid traži izričito „da”. Tapneš mic, kažeš što trebaš, odgovor se pročita naglas (OpenAI glas ili glas uređaja, brzina 1×–2×). Dok je ekran otvoren, najavi sesije koje te počnu trebati. Jedan operator za sve uređaje; nakon sat vremena mirovanja dobije /clear i kreće ispočetka.

17 · MemosSnimi razgovor#/memos

Voice memos: sastanak postaje transcript

Jedan gumb snima razgovor bez limita trajanja. Audio se reže u segmente od 5 minuta koji se transkribiraju dok snimanje traje, a na kraju memo dobije naslov i sprema se kao markdown. Ništa se ne gubi: chunkovi idu u IndexedDB dok ih server ne potvrdi, prekinuto snimanje se spasi kod sljedećeg otvaranja. Iz memoa jednim klikom Start session; vokabular (imena ljudi, domenski pojmovi) poboljšava transkripciju.

18 · NotesMarkdown explorer#/notes · ⌘⇧E

Bilješke bilo kojeg hosta

Ako host ima web.notes.root, Fleet u panelu pored liste pokazuje stablo foldera, nedavno mijenjane bilješke i pretragu (riječi, "fraze", #tag) s istaknutim pogocima. Bilješka se prikazuje renderirana s frontmatterom kao tablicom i [[wiki]] linkovima. Send to session stavi putanju bilješke u composer odabrane sesije. Paleta ⌘K pretražuje i bilješke.

19 · UsageLimiti pretplate#/usage · fleet usage · ⌘⇧U

Koliko je još ostalo do limita

Isti brojevi kao Claude Codeov /usage i Codexov /status, za svaki account logiran na nekoj mašini (hostovi na istom accountu dijele karticu): Claude (trenutna sesija, tjedni limit, tjedni po modelu, extra usage) i ChatGPT plan koji koriste Codex i pi (5-satni prozor, tjedni limit). Limit koji trenutno veže je označen kao binding, a reset piše kad.

20 · OporavakInactive i Closedfleet restore · fleet sleep

Ništa se ne gubi: Inactive i Closed

Fleet stalno sprema snapshot tmux layouta. Nakon reboota sesije postanu Inactive (bivši „dormant”): vide se ispod liste i na boardu, sa svih hostova zajedno, najnovije gore, svaka sa svojim hostom. Resume vrati isti layout i svaki Claude pane s --resume, pa grupe, stackovi i briefovi ostaju. Deactivate (u ⏻ meniju, CLI fleet sleep) zatvori sesiju a ostavi je u Inactive, za posao kojem ćeš se vratiti. Closed čuva zatvorene sesije 7 dana, za slučaj da si zatvorio krivu.

fleet restore              # lista inactive sesija
fleet restore legacy-import
fleet restore --all        # sve osim deaktiviranih
fleet restore --closed     # nedavno zatvorene
fleet sleep invoice        # zatvori, ali zadrži u Inactive
21 · PostavkeIzgled, modeli, repoi#/settings · ⌘,

Teme, modeli i postavke flote

Settings ima podstranice. General je po pregledniku: veličina teksta, paleta (Suite iz zajedničkog design systema je default; Graphite, Earth, Dusk), light/dark/system, progress notes i send delay. Ostalo se sprema u config svakog hosta:

  • Models: default model i effort po harnessu (Claude Code, Codex, pi), za sve što krene bez odabranog modela: web, CLI, botovi i zakazane sesije.
  • Start directories: labela s putanjom po hostu; svaka ćelija pokaže postoji li direktorij, Save piše na sve hostove. Skriveni unosi su dopušteni za spawn, ali se ne nude u New session.
  • Git repos: auto-sync (launchd timer), interval, skenirani direktoriji i svaki repo s branchom, ↓↑, zadnjim syncom i ishodom. Sync now po repou ili Sync all.
  • Inbox: kad se skeniraju Slack i email. Status: hostovi i dijagnostika.
22 · TerminalCLI i TUIfleet

Isto, iz terminala

Goli fleet je živi dashboard: sesije sortirane da one koje te trebaju budu gore, prompt i repo ispod naslova, događaji (pojavila se, završila, zapela dulje od 300 s) u donjem panelu. Brojevi 1–0 skaču na sesiju.

fleet list -a                          # sve sesije, svi hostovi (--json: jedan array)
fleet peek invoice                     # što sesija trenutno pokazuje
fleet send invoice "run the tests"     # utipkaj i stisni Enter
fleet -H workstation spawn "migrate the index" --dir ~/Code/acme-api --harness codex
fleet spawn --from invoice             # nova sesija iz briefa
fleet handoff --dir ~/Code/acme-api     # prebaci ovaj posao u novu sesiju, s briefom
fleet pr spawn acme-web#1310           # PR u worktree + sesija na njemu
fleet name --apply                     # daj svim sesijama prava imena
fleet enter invoice · fleet last       # uđi u tmux sesiju bilo gdje · natrag na prethodnu
fleet tmux stale                       # idle shellovi koje nitko ne koristi
fleet brief invoice · fleet stack …    # briefovi i stackovi
fleet tasks · fleet task spawn 2041     # Productive taskovi, sesija na tasku
fleet schedule add "…" --at "tomorrow 07:30"   # sesija kasnije
fleet slack link <thread-url> --for 2h  # sesija razgovara u Slack threadu
fleet done --note "…" · fleet sleep invoice     # javi gotovo · zatvori u Inactive
fleet repos sync · fleet bots run dependency-audit
fleet doctor                           # dostupnost hostova, verzije, config

Target se resolva po naslovu, imenu, prefiksu session id-ja ili pidu. Komande koje tipkaju u živog agenta nikad ne pogađaju: ako dvije sesije jednako odgovaraju, dobiješ grešku s kandidatima.

23 · AgentiMCP, skill, sigurnost

Agenti upravljaju flotom sami

fleet mcp

Svaka CLI komanda kao MCP tool, generiran iz CLI definicija. stdio za Claude Code, --http sa bearer tokenom za ostale.

fleet skill install

Skill koji uči Claudea kad i kako koristiti fleet: „what's my fleet doing”, „spawn a session to…”, „take this to another terminal”.
